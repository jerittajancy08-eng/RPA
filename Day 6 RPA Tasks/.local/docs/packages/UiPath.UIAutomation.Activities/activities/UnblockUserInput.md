## XAML Example

Run `uip rpa --help` to find the command that retrieves the default XAML for an activity, then run it with the class name `UiPath.UIAutomationNext.Activities.NUnblockUserInput`.

## Notes

- No mandatory parent scope is required for this activity.
- This activity is used to restore keyboard and mouse input that was previously blocked by a **Block User Input** activity.
- Typically used when `DisableUnblock` was set to true on the corresponding Block User Input activity.
